# 최종 통합 전 복구할 임시 개발 설정

이 문서는 후반 콘텐츠를 빠르게 수동 검증하기 위해 임시로 비활성화하거나 변경한 규칙을 모은다.
기업 콘텐츠 단계 0~8 구현 중에는 유지하고, 단계 9 통합 검증을 시작할 때 한 항목씩 복구한다.
아래 항목이 모두 완료되기 전에는 기업 콘텐츠를 최종 완료로 판단하지 않는다.

## 기업 개방과 설립

- [ ] 기업 탭 상시 노출 제거
  - 현재: 로그인한 플레이어는 진행도와 관계없이 기업 탭에 접근할 수 있다.
  - 최종: 서울 최종 건물 구매 6게임개월 후 설립 제안 사건을 거쳐 기업 탭을 개방한다.
  - 검증: 조건 전에는 탭 잠금, 조건 달성일에는 제안 1회, 수락 후 준비화면 접근.

- [ ] 비서 성장조건 복구
  - 현재: 비서 6명의 숙련도·호감도가 최대가 아니어도 설립할 수 있다.
  - 최종: 비서 6명 전원의 숙련도 30·호감도 30을 설립 필수조건으로 검사한다.
  - 검증: 한 명이라도 미달이면 설립 불가, 모두 충족하면 설립 가능.

- [ ] 부동산 인계조건 복구
  - 현재: 여섯 도시에 관리직원이 모두 없어도 설립할 수 있다.
  - 최종: 청주·세종·대전·부산·인천·서울 관리직원 배치를 설립 필수조건으로 검사한다.
  - 검증: 한 도시라도 미배치 또는 급여중단이면 설립 불가.

## 부동산 관리직원

- [ ] 관리직원 채용 시점 복구
  - 현재: 기업 기능 개발을 위해 도시·비서 성장조건 없이 관리직원을 채용할 수 있다.
  - 최종: 해당 도시 담당 비서의 숙련도 30·호감도 30과 기업 설립 준비단계 진입을 요구한다.
  - 검증: 조건 전에는 채용 버튼 잠금, 조건 충족 후 채용 가능.

## QA 도구

- [ ] 상용화 개발 즉시 완료 기능 제거
  - 현재: 기업 화면의 `QA · 4개월 개발 건너뛰기` 버튼으로 비용과 게임시간을 소모하지 않고 출시 검토 단계로 이동한다.
  - 최종: 버튼과 `/test/company/commercialization/skip` 엔드포인트 및 테스트 전용 도메인 전환 메서드를 제거한다.
  - 검증: 최초 상용화는 실제 월 정산 네 번을 거쳐야만 출시 검토 단계가 된다.

- [ ] 현금 1조원 지급 버튼 정리
  - 현재: 후반 콘텐츠 테스트를 위해 기존 테스트 현금 지급량을 1조원으로 사용한다.
  - 최종: 운영 빌드에서 QA 패널과 엔드포인트를 숨기거나 개발 프로필로 제한한다.
  - 검증: 일반 실행 환경에서 QA 명령 접근 불가.

## 화면의 개발 표시

- [ ] `개발 중 조건 미적용`, `검증 보류`, `준비 중` 문구 제거
  - 현재: 기업 준비·완료 화면에 미구현 상태와 우회조건을 표시한다.
  - 최종: 실제 조건과 실제 데이터만 표시하고 예시 대시보드 데이터는 제거한다.
  - 검증: 기업 화면 전체에서 개발용 문구와 예시 수치 검색 결과가 없어야 한다.

## 최종 확인 절차

1. 위 체크리스트를 모두 복구한다.
2. 신규 계정으로 부동산 시작부터 기업 설립까지 정상 진행한다.
3. 조건 직전·직후 저장파일을 각각 만들어 해금과 설립 차단을 확인한다.
4. 개발 프로필과 일반 프로필에서 QA 기능 노출 차이를 확인한다.
5. QA 상용화 건너뛰기 없이 실제 4개월 개발과 출시 전환을 확인한다.
6. `PLAYER_COMPANY_V1_DESIGN.md`의 단계 9 통합 검증 결과와 함께 이 문서를 완료 처리한다.
